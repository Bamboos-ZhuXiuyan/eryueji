# 二月季 · 校园闲置流转平台

一个校园二手物品交易的单页站点，纯静态，双击 `index.html` 就能跑。

对应《校园二手物品交易 创新创业计划书》里「撮合线 + 寄卖线 + 集市线」的线上部分。

## 怎么用

直接打开 `index.html` 即可。无须构建、无须服务器、无须数据库。

放到 GitHub Pages：

1. 新建仓库，把 `index.html` 传到根目录
2. Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
3. 等一分钟，访问 `https://<用户名>.github.io/<仓库名>/`

本地起服务器也行（手机上同局域网访问）：

```bash
python -m http.server 8000
```

## 功能

| 模块 | 说明 |
|---|---|
| 在售闲置 | 12 件示例商品，卡片网格自适应 1–4 列 |
| 多条件筛选 | 品类 8 类、成色 5 档、关键词搜索，可叠加 |
| 排序 | 最新发布 / 离我最近 / 价格升降 / 成色优先 |
| 商品详情 | 弹窗展示成色、自提点、院系、卖家信用分与历史成交量 |
| 我要发布 | 表单校验（标题必填、价格非负），即时上架并置顶 |
| 我的发布 | 只看自己发的，可下架 |
| 求购专区 | 买家发布预算与用途，与在售区分离 |
| 想要收藏 | 星标收藏，统计栏实时计数 |
| 绿色积分 | 按商品重量估算减碳量，对应计划书的公益闭环 |

## 技术选型（按你的要求）

- **单文件**：只有 `index.html`，HTML + 原生 JavaScript
- **零 CSS 文件**：全部用行内 `style` 属性，`<style>` 标签数量为 0，没有外部样式表
- **无数据库**：数据存在浏览器 `localStorage`，键名 `eryueji_items_v1` / `eryueji_saved_v1`
- **无依赖**：不引 CDN，不引框架，断网也能看
- **无图片文件**：商品图用品类 emoji + 渐变底色，仓库里不会有一堆图

## 关于数据

首次打开会写入 12 条种子数据，之后的发布、收藏、下架都记在本地浏览器。

这意味着：**数据不跨设备、不跨浏览器、别人访问看不到你发的商品**。这是纯静态页面的固有限制，也是「不做数据库」的代价。

想清空重来，在控制台执行：

```js
localStorage.removeItem('eryueji_items_v1');
localStorage.removeItem('eryueji_saved_v1');
location.reload();
```

要改成真的多人能用，就得加后端（Node/Python + 任意数据库），或者用 Supabase、LeanCloud 这类 BaaS。现在的版本适合做展示和答辩演示。

## 页面结构

```
index.html
├─ header   粘性导航：Logo / 搜索框 / 发布按钮
├─ hero     标语 + 三张统计卡（在售数 / 想要数 / 减碳量）
├─ tabs     在售闲置 · 求购专区 · 我的发布
├─ filter   品类 chip · 成色 chip · 排序下拉
├─ main     商品网格（JS 渲染）
├─ footer   项目信息
└─ modals   商品详情弹窗 · 发布弹窗 · Toast
```

## 改内容在哪

都在 `<script>` 开头的常量区：

```js
var CATS  = [...];   // 品类，改这里会同步筛选栏和发布下拉
var CONDS = [...];   // 成色五档
var LOCS  = [...];   // 自提点
var SEED  = [...];   // 12 条示例商品
var WANTS = [...];   // 求购数据
```

配色集中在 `CATCOLOR`（品类渐变底色）和几处 `#1e6fd9`（主色蓝）。
